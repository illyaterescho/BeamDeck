# BeamDeck 0.3

Пульт для Android-проєктора на зразок Magcubic HY350 MAX. На проєкторі працює **приймач BeamDeck**, який сам виконує всі команди. Телефон керує ним через **Bluetooth LE**, так само як Lumina Go. Wi-Fi потрібен лише для живого зображення екрана та вебпульта.

```
iPhone / Mac (BeamDeck, SwiftUI) ──BLE, шифрування──▶ приймач на проєкторі ──▶ ADB loopback  (будь-яка кнопка, фокус, живлення)
Браузер (вебпульт)              ──Wi-Fi :8765──────▶                        └─▶ спеціальні можливості (стрілки, OK, курсор)
```

## Чому в 0.2.2 кнопки не працювали

1. Стрілки й OK викликали `GLOBAL_ACTION_DPAD_*`, яких до Android 13 немає. На прошивках 9–12 вони завжди поверталися як `unsupported`.
2. Фокус і частину навігації BeamDeck надсилав на «приймач Lumina» за адресою `:8899/api/v1/...`. Такого API не існує. Lumina Go Receiver (`com.htc.btremote.receiver.gtv`) працює лише через BLE і навіть не має дозволу на інтернет.
3. Служба спеціальних можливостей бачила лише власний пакет і не могла переміщувати фокус в інших програмах.

## Як 0.3 виконує команди на проєкторі

| Шлях | Що дає | Що потрібно |
| --- | --- | --- |
| **ADB через `127.0.0.1:5555`** | `input keyevent` на будь-якій версії Android: стрілки, меню, живлення, сон, а також навчені кнопки фокуса й трапеції | Один раз увімкнути налагодження і натиснути «Дозволити» на екрані проєктора |
| **Спеціальні можливості** | Back/Home миттєво, стрілки через обхід фокуса (Android 8–12) або DPAD (13+), OK, курсор-тачпад, натискання за координатами | Увімкнути «BeamDeck · Навігація» |
| AudioManager / MediaSession | Гучність, медіакнопки, таймер сну | Доступ до сповіщень (для медіа) |

Приймач сам обирає найсильніший доступний шлях. Якщо дія недоступна, пульт показує, що саме ввімкнути.

## Нове

- **Програма BeamDeck для iPhone і Mac** (`apple/`): пошук проєктора поруч, код потрібен лише один раз, токен зберігається в Keychain, після цього програма підключається автоматично.
- **Пульт:** коло-клікер зі свайпами, утримання стрілки повторює її, утримання OK дає довге натискання. Також Назад/Додому/Меню, медіа, гучність і фокус з утриманням для мотора.
- **Тачпад:** курсор на проєкторі з прискоренням, натискання дотиком, смуга прокрутки.
- **Екран:** живе зображення проєктора через Wi-Fi. Торкніться картинки, щоб натиснути в цьому місці.
- **Програми:** пошук, обрані, запуск.
- **Навчання кнопок:** «Навчити» → натиснути кнопку на фізичному пульті. Так BeamDeck вивчає фокус, трапецію й будь-які дві свої кнопки.
- **Живлення:** сон, пробудження, вимкнення.
- **Приймач:** екран у стилі tvOS зі станом кожного шляху, автозапуск після ввімкнення проєктора, BLE з шифруванням ECDH P-256 + AES-GCM ([PROTOCOL.md](PROTOCOL.md)).
- **Вебпульт:** перероблено під палітру Apple. Геометрія, плеєр і профілі з 0.2 на місці.

## Налаштування проєктора (один раз)

1. Установіть `BeamDeck-Agent-0.3.1.apk` з USB і відкрийте **BeamDeck**. Приймач запускається сам і показує код.
2. Дозвольте «Пристрої поблизу», щоб працював Bluetooth.
3. **Навігація:** рядок «Навігація» → «Спеціальні можливості» → «BeamDeck · Навігація» → увімкнути. Якщо Android блокує, спершу «Інформація про програму → ⋮ → Дозволити обмежені налаштування».
4. **Системні кнопки (рекомендовано):** «Налаштування → Про пристрій», сім разів натиснути «Номер збірки». Потім «Для розробників» → увімкнути налагодження USB або «по мережі». Коли з’явиться «Дозволити налагодження?», позначте «Завжди» і натисніть OK. Рядок «Системні кнопки» стане зеленим.
5. За бажанням увімкніть клавіатуру BeamDeck і доступ до сповіщень (рядки «Клавіатура» та «Медіа»).

## iPhone

Відкрийте `apple/BeamDeck.xcodeproj` у Xcode. У **Signing & Capabilities** виберіть свою Apple ID (Personal Team), підключіть iPhone і натисніть Run. Програма знайде проєктор поруч і попросить код з його екрана. Без проєктора інтерфейс можна подивитися з аргументом запуску `-demo`.

## Збірка

```bash
export JAVA_HOME=/opt/homebrew/opt/openjdk@17 ANDROID_HOME=$HOME/Library/Android/sdk
cd web && npm ci && npm run test:geometry && npm run build
cd ../android && ./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
cd ../apple && xcodegen generate && xcodebuild -scheme BeamDeck -destination 'generic/platform=iOS' build
```

## Що перевірено, а що ні

Перевірено на емуляторі Android TV 12:
- автозапуск приймача й BLE-реклама;
- запит ADB і перехід у «готово» після «Дозволити»;
- рух фокуса стрілками з пульта без ADB (Android 12);
- Home, Menu через ADB, список програм, JPEG екрана;
- сопряження за кодом.

Крім того:
- шифрування Kotlin ↔ CryptoKit збігається в обидва боки (юніт-тест);
- iOS- і macOS-збірки компілюються, інтерфейс перевірено в демо-режимі на Mac;
- вебпульт пройшов typecheck, тести геометрії та збірку.

**Не перевірено, потрібен реальний проєктор і iPhone:**
- BLE-з’єднання iPhone ↔ HY350 (емулятор не приймає BLE-підключень);
- **навчання кнопок з фізичного пульта**: Android не пропускає штучні натискання через фільтр спеціальних можливостей, тож на емуляторі цей шлях не відтворюється;
- які коди клавіш прошивка Magcubic використовує для фокуса;
- чи дозволяє прошивка loopback ADB і чи пам’ятає вона «Завжди дозволяти». На емуляторі ключ не зберігався між перезапусками, тому запит з’являвся знову.

Не підтримується: системний автофокус і трапеція без кнопок на пульті, адже публічного API виробника немає.
