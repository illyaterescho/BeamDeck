# BeamDeck

Пульт для проєкторів Magcubic / HTC / WEMI на iPhone і Mac. Керує проєктором **напряму по Bluetooth через його вбудований приймач**, той самий, яким користується Lumina Go. На проєктор нічого не встановлюється, Wi-Fi не потрібен.

## Що вміє

- **Пульт:** D-pad зі свайпами й утриманням, OK, Назад, Додому, Меню, медіа, гучність, фокус з утриманням для мотора, живлення.
- **Швидкі розділи:** налаштування проєктора, усі програми, джерело сигналу (HDMI), трансляція з телефона, ярлики YouTube / Netflix / Disney+ / Prime Video / USB.
- **Трапеція з телефона:** відкриваєте меню трапеції на проєкторі й регулюєте кути D-pad’ом на тому ж екрані.
- **Макроси:** записуєте шлях кнопками (наприклад «Налаштування → ↓ ↓ → OK» до трапеції чи режиму зображення) і відкриваєте його одним дотиком або голосом: «макрос трапеція».
- **Пульт на екрані блокування і в Dynamic Island:** Назад, Додому, пауза й гучність, поки проєктор під’єднано.
- **Тачпад з мультитачем:** курсор, клік, прокрутка двома пальцями, правий клік, перетягування.
- **Повітряна миша:** ведете телефоном, курсор іде за ним.
- **Голос українською:** «вниз три рази і ок», «гучність тридцять», «відкрий ютуб», «знайди мультики», «напиши Дюна», «фокус ближче».
- **Текст і посилання:** клавіатура з телефона в будь-яке поле, вставити з буфера, відкрити посилання на проєкторі.

Протокол приймача описано в [LUMINA_PROTOCOL.md](LUMINA_PROTOCOL.md).

## Що працює на будь-якому проєкторі, а що ні

Приймач не виконує команди сам, а перетворює їх на натискання клавіш Android. Стрілки, OK, Назад, Додому, Меню, гучність і фокус ± — звичайні клавіші, вони працюють. Трапеція (код 332), автофокус (319), яскравість, колір, режими та сторінки налаштувань — фірмові коди й «спеціальні» команди, які прошивка HY350 MAX ігнорує. Тому в BeamDeck їх немає, а до цих меню ведуть макроси.

Точний рівень гучності приймач не повідомляє, тому повзунок показує останнє значення, виставлене з телефона.

## Встановлення на iPhone

1. Відкрийте `apple/BeamDeck.xcodeproj` у Xcode.
2. **Signing & Capabilities** → Team: ваш Apple ID (безкоштовний Personal Team підходить).
3. Під’єднайте iPhone, увімкніть на ньому «Режим розробника», натисніть Run.

З безкоштовним акаунтом програма працює 7 днів, потім знову Run. Без проєктора інтерфейс можна подивитися з аргументом запуску `-demo`.

## «Поділитися» → на проєктор

У «Командах» створіть команду з «Показувати в меню Поділитися», дія «Відкрити URL» зі значенням `beamdeck://open?url=` + «Вхід команди». Посилання з Safari чи YouTube відкриватиметься на проєкторі.

## Перевірки

```bash
swiftc -parse-as-library -o /tmp/voicetest apple/BeamDeck/Model/VoiceCommands.swift apple/Tools/VoiceCommandsTests.swift && /tmp/voicetest
cd apple && xcodegen generate && xcodebuild -scheme BeamDeck -destination 'generic/platform=iOS' build
```

## Якщо на проєкторі лишився BeamDeck Agent

Попередні версії ставили на проєктор програму BeamDeck Agent. Вона більше не потрібна: Налаштування проєктора → Програми → BeamDeck Agent → Видалити.
