# BeamDeck 0.2.2

BeamDeck Agent запускає локальний HTTP/WebSocket-сервер на Android-проєкторі та роздає BeamDeck Remote. Відкривайте пульт у Safari на iPhone або в браузері Mac через ту саму Wi-Fi мережу. Інтернет потрібен для завантаження інструментів і залежностей під час першої збірки. Пульт і Agent спілкуються напряму.

## Що є в цій папці

- `android/` — код Android Agent, Gradle Wrapper та налаштування збірки.
- `web/src/` і `web/public/` — код вебпульта й статичні ресурси.
- `web/dist/` — зібраний вебпульт, який також вбудовано в APK.
- `BeamDeck-Agent-0.2.2.apk` — інсталяційний APK із debug-підписом.
- `BeamDeck-Cinema-demo.html` — автономне демо для браузера.
- `API.md` — документація локального API.

## Швидкий старт

- **Демо на Mac.** Відкрийте `BeamDeck-Cinema-demo.html` у браузері. Це самодостатній файл із демонстраційним Agent. Для роботи з реальним проєктором відкрийте адресу, яку показує Agent.
- **На проєкторі.** Установіть `BeamDeck-Agent-0.2.2.apk` і увімкніть сервер. Сервер слухає порт **8765** на приватній IPv4-адресі Wi-Fi або Ethernet.
- **На iPhone чи Mac.** Відскануйте QR-код камерою iPhone або введіть показану адресу, наприклад `http://192.168.1.24:8765`. Введіть шестизначний PIN з екрана Agent.

## Встановлення на Magcubic HY350 MAX

1. У меню проєктора відкрийте інформацію про пристрій і перевірте версію Android. Мінімальна версія для APK — Android 8.0 (API 26). Стрілки й OK потребують Android 13 (API 33) або новішого та відповідних системних дій у прошивці.
2. Скопіюйте APK на USB-накопичувач. Під’єднайте його до проєктора, знайдіть APK через файловий менеджер і відкрийте його. Якщо Android запитає дозвіл на встановлення з цього джерела, надайте його файловому менеджеру й повторно відкрийте APK. Назви меню залежать від прошивки.
3. Запустіть **BeamDeck Agent** і виберіть **Увімкнути сервер**. Дочекайтеся адреси, QR-коду й PIN. За бажанням надайте дозвіл на показ сповіщення Agent. У сповіщенні є кнопка зупинки сервера.
4. Під’єднайте iPhone або Mac до тієї самої мережі, відкрийте адресу з кроку 3 і введіть PIN. Якщо код прострочився, виберіть **Новий PIN** на проєкторі. У гостьовій Wi-Fi мережі ізоляція клієнтів може блокувати пряме з’єднання.
5. Для Back, Home, стрілок, OK і запуску програм із фону виберіть **Спеціальні можливості** в Agent і ввімкніть **BeamDeck · Навігація**. Для медіакоманд виберіть **Доступ до сповіщень для медіа** й надайте доступ **BeamDeck · Медіа**. Відкрийте плеєр і почніть відтворення, щоб Android опублікував медіасесію.
6. На iPhone в Safari відкрийте меню сторінки, виберіть **Поділитися → На початковий екран**, а потім **Відкрити як вебпрограму**, якщо ця опція є у вашій версії iOS. Якщо вебпрограма відкрилася з окремим сеансом, повторіть pairing. [Інструкція Apple](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios).
7. Спершу перевірте гучність, потім запустіть встановлену програму й перевірте медіакнопки з активним відтворенням. Сервер можна вимкнути в Agent або через сповіщення.

Android може обмежувати спеціальні можливості або доступ до сповіщень для встановлених вручну програм. Якщо прошивка пропонує системну дію **Дозволити обмежені налаштування** для BeamDeck, застосуйте її лише до довіреної копії APK. Якщо такого пункту немає або доступ заблоковано виробником, пульт покаже відповідні дії як недоступні. Гучність від цих двох служб не залежить. [Довідка Android про обмежені налаштування](https://support.google.com/android/answer/12623953).

Якщо на проєкторі вже є BeamDeck, підписаний іншим ключем, Android може відхилити оновлення. Для першої інсталяції використайте наданий APK. Для подальших збірок зберігайте власний ключ підпису. Видалення попередньої установки видаляє її сеанси.

## Оновлення 0.2.2

BeamDeck шукає сумісний приймач Lumina Go на порті 8899 самого проєктора. Якщо приймач повідомляє про підтримку, кнопки навігації, гучності та фокуса використовують штатні команди прошивки. Зв’язок між браузером і BeamDeck як і раніше потребує PIN. Користувач не задає адресу приймача. [Документація Lumina Go](https://docs.luminago.app/).

Слайдер надсилає перше значення одразу, а під час руху відправляє найсвіжіше значення приблизно кожні 180 мс. Android Agent повертає фактичний рівень і запитує системну панель через AudioManager. Відображення панелі на конкретному проєкторі визначає прошивка. [Довідник AudioManager](https://developer.android.com/reference/android/media/AudioManager#FLAG_SHOW_UI).

На фізичному проєкторі перевірено штатні команди Lumina Go для гучності зі збереженням початкового рівня. Щоб перевірити плитку навігації, мотор фокуса й вигляд панелі саме через BeamDeck, установіть новий APK, запустіть сервер і оновіть сторінку пульта.

## Оновлення 0.2.1

Установіть APK поверх 0.2.0, відкрийте Agent і знову ввімкніть сервер. На екрані Agent можна відкрити **Тестову сітку на проєкторі** або **Плеєр BeamDeck** окремими кнопками. Локальна кнопка сітки працює з вимкненою навігацією. Екран пульта відкривається на телефоні, а сітка та плеєр відкриваються на проєкторі.

Після підключення натисніть **Home** на проєкторі для переходу в іншу програму. Поки сервер Agent працює у фоні, пульт зберігає доступ до нього. При примусовій зупинці Agent, вимкненні сервера або перезавантаженні проєктора сервер треба знову ввімкнути. Згортання Safari на телефоні залишає парний сеанс у cookie.

Служба BeamDeck Navigation тепер декларує подію зміни вікна для власного пакета. Екран Agent показує, чи Android справді підключив службу. Якщо Android показує обмеження для вручну встановленої програми, відкрийте **Інформація про BeamDeck → ⋮ → Дозволити обмежені налаштування**, якщо прошивка показує цей пункт. Далі поверніться в спеціальні можливості. [Довідка Android](https://support.google.com/android/answer/12623953).

На емуляторі Android 14 перевірено локальне відкриття сітки з вимкненою навігацією та роботу парного API після натискання Home. Відповідність перемикача прошивці HY350 MAX треба перевірити на фізичному пристрої.

## Нове у 0.2

### Введення з iPhone

1. На проєкторі відкрийте BeamDeck Agent, натисніть **Увімкнути клавіатуру BeamDeck** і дайте Android дозвіл. Далі виберіть її кнопкою **Вибрати клавіатуру**. Після введення можна повернути попередню клавіатуру тим самим меню.
2. На проєкторі відкрийте браузер і поставте курсор в адресний рядок. У вебпульті відкрийте піктограму клавіатури поруч із перемикачем **Стрілки / Дотик**.
3. Натисніть і утримуйте поле на iPhone, виберіть **Вставити**, потім натисніть **Надіслати в поле**. **Enter** виконує дію поточного поля. Кнопка **Відкрити URL** передає абсолютну адресу HTTP/HTTPS безпосередньо браузеру Android. Для запуску у фоні потрібна служба спеціальних можливостей BeamDeck.

Клавіатура вводить текст у позицію курсора або замінює виділення. Дії в захищених полях Android блокуються. У локальному HTTP-режимі користуйтеся системним меню «Вставити». Android Agent не записує надісланий текст у буфер обміну.

### Сітка, трапеція й фокус

- У **Екран → Геометрія** перетягніть будь-який із чотирьох кутів. Маркери працюють незалежно й підтримують кілька дотиків. На Mac стрілки зсувають активний кут, Shift збільшує крок. Undo повертає попередню геометрію, Reset повертає повний кадр.
- **Сітка** відкриває повноекранний патерн Android. Під час перетягування браузер показує гомографію одразу й надсилає лише найновішу проміжну позицію до 20 разів на секунду. Agent перевіряє опуклість, межі й мінімальний розмір, застосовує її до сітки та зберігає остаточну позицію після завершення жесту.
- **Auto Keystone з фото** відкриває майстер. Поставте iPhone перед серединою екрана паралельно стіні й сфотографуйте всі кольорові мітки. Браузер локально оцінює перспективу, відтінок білого, розкид яскравості та відносну різкість п’яти зон. Підтвердьте профіль і за потреби поверніться до ручної корекції. Різкість і колір залежать від автоекспозиції, кута зйомки й камери телефона.
- BeamDeck коригує свою сітку й локальне відео. Для системної трапеції та фокуса скористайтеся **Налаштування проєктора** і D-pad на пульті, якщо прошивка має відповідний екран. На пристрої можна переглянути діагностику доступності пакета виробника через API. Публічний API двигуна об’єктива та Auto Keystone виробника не підтверджений. [Інструкція Magcubic з фокусування](https://www.youtube.com/watch?v=DBsnB9Fy8Ng).

### Плеєр і профілі

У **Екран → Плеєр** відкрийте плеєр і виберіть локальний відеофайл на проєкторі. Для субтитрів виберіть SRT або WebVTT. Проєктивне перетворення діє у відеоповерхні. У вкладках зображення, звуку й субтитрів можна окремо зберегти налаштування. Порівняння оригіналу та обробки накладається на один кадр.

- **Зображення.** GPU-шейдер на Android 13+ обробляє колір, гаму, контраст і тіні. Адаптивні тіні враховують виміряну яскравість. Просторове згладжування пом’якшує дрібний шум і блокові межі зі збереженням сильних країв. Економний режим і падіння частоти кадрів прибирають дорожче згладжування.
- **Звук.** Еквалайзер підсилює мовний діапазон. Нічний режим і регульована компресія використовують Android DynamicsProcessing, якщо Android надає його для цього сеансу.
- **Профілі.** Збережіть геометрію, параметри плеєра, гучність і таймер. Профіль можна перейменувати, скопіювати й перенести JSON-файлом. Кінорежим застосовує профіль, встановлює гучність, відкриває BeamDeck Player і за потреби ставить таймер.

В аналізі фото та ефектах використовуються класичні алгоритми. Апаратний фокус, системний Auto Keystone, вимірювання гучності за LUFS, керування RGB-підсвіткою й інтерполяція кадрів залишаються окремими напрямами. Плеєр працює з локальним контентом і стандартними декодерами Android.

## Що зроблено

| Дія | Реалізація та статус |
| --- | --- |
| Гучніше, тихіше, Mute, слайдер | Android `AudioManager` для потоку `STREAM_MUSIC`. Agent перевіряє фактичне значення після зміни. Фіксована гучність позначається як недоступна. |
| Play/Pause, Previous, Next | Активна Android `MediaSession` з дозволом доступу до сповіщень. Пульт враховує дії, оголошені поточним плеєром. `submitted` означає, що Android прийняв медіаподію для доставки. Поточний стан відтворення оновлюється окремо. |
| Back і Home | Офіційні глобальні дії Android AccessibilityService. Agent повертає помилку, якщо Android повернув `false`. |
| Стрілки, OK, сенсорна панель | Із Android 13 та за наявності системних D-pad дій. Свайп відправляє одну стрілку, дотик відправляє OK. |
| Список і запуск програм | Список активних точок запуску `LEANBACK_LAUNCHER` і `LAUNCHER` з Android PackageManager. Показуються програми, встановлені на пристрої. Для запуску із фону потрібна активна служба BeamDeck Navigation. `submitted` означає переданий Android запит на відкриття. |
| Обрані програми й налаштування | Збереження в браузері окремо для демо й реального режиму. Сеанс pairing зберігається в cookie браузера. |
| Movie Night | Agent встановлює заданий відсоток гучності та просить Android відкрити вибраний плеєр. Якщо гучність змінилась, а Android явно відхилив запуск, API повертає `partial_scene`. |
| Таймер сну | Android Agent тримає відлік, навіть якщо сторінку пульта закрито. Після відліку Agent вимикає звук, перевіряє його стан і передає команду паузи, якщо вона доступна. Пульт показує результат таймера. Зупинка Agent скасовує відлік. |
| Вібровідгук | Вебпульт використовує `navigator.vibrate` у браузерах, які його підтримують. Відсутність API видно в налаштуваннях. |

Доступ до мотора фокуса, системної трапеції, яскравості лампи та живлення залежить від документованих інтерфейсів прошивки. Розділ «Екран» дає доступ до оптичних налаштувань через штатний лаунчер, якщо він доступний.

## Дозволи й життєвий цикл Android

| Дозвіл або доступ | Для чого |
| --- | --- |
| `INTERNET`, `ACCESS_NETWORK_STATE` | Сокети сервера, визначення локального інтерфейсу та перепідключення після зміни мережі. |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_CONNECTED_DEVICE`, `CHANGE_NETWORK_STATE` | Foreground service типу `connectedDevice` для локального зв’язку на Android 14. `CHANGE_NETWORK_STATE` задовольняє вимогу типу сервісу. Agent використовує поточне з’єднання пристрою. |
| `POST_NOTIFICATIONS` | Показ сповіщення Agent на Android 13+. Доступ запитується на екрані Agent. |
| `MODIFY_AUDIO_SETTINGS` | Зміни гучності та mute/unmute. |
| AccessibilityService, за згодою | Глобальні дії та запуск програм із фону. Доступ до вмісту вікон вимкнено в конфігурації. |
| NotificationListenerService, за згодою | Доступ Android для пошуку й керування активними `MediaSession`. Agent використовує цей доступ через MediaSessionManager. |

Користувач запускає foreground service з видимого екрана Agent. Сервіс працює, поки проєктор відкриває інші програми, і зупиняється за командою користувача. Після примусової зупинки або перезавантаження його потрібно ввімкнути вручну. Android може відкласти виконання таймера у глибокому сні. Служба використовує неточний системний будильник.

## Локальна мережа та PWA

Парний сеанс діє до 30 днів і відкликається з пульта або кнопкою **Завершити всі сеанси** на проєкторі. Якщо змінилася IP-адреса, відкрийте нову адресу з екрана Agent. Cookie попередньої адреси належить до іншого джерела, тож знадобиться PIN. DHCP reservation у роутері дозволяє зберегти одну адресу.

Трафік LAN передається через HTTP і WS без шифрування. Використовуйте пульт у довіреній мережі. Android Agent перевіряє адресу призначення, локальну підмережу, джерело браузерних запитів, PIN, формат даних і сеанс. Сервер не потрібно відкривати назовні.

Маніфест і іконки підтримують запуск з початкового екрана iPhone. Для Service Worker потрібен безпечний контекст, тож звичайний `http://192.168.x.x` забезпечує керування онлайн через LAN, а кеш вебінтерфейсу доступний на HTTPS або localhost. Для виконання команд потрібне з’єднання з проєктором. [Специфікація Service Worker](https://www.w3.org/TR/service-workers/).

## Збірка на Mac з Apple Silicon

Потрібні Node.js 20.19+ (гілка 20) або 22.12+, npm, JDK 17 і Android SDK Platform 35 з Build Tools 34.0.0. Установіть їх через Android Studio або командні інструменти Android SDK. Указуйте шлях до свого встановленого SDK.

```bash
export JAVA_HOME="$(/usr/libexec/java_home -v 17)"
export ANDROID_HOME="$HOME/Library/Android/sdk"
```

Відкрийте папку розпакованого проєкту й запустіть:

```bash
cd web
npm ci
npm run dev
```

Команда відкриє Vite в деморежимі. Для власного HTML-демо виконайте `npm run demo:html`. Файл з’явиться у `web/beamdeck-demo.html`.

Для складання APK з кореня проєкту:

```bash
cd web
npm ci
npm run test:geometry
npm run build
cd ../android
./gradlew :app:assembleDebug :app:lintDebug
```

Gradle Wrapper завантажує Gradle 8.9 і перевіряє контрольну суму. Збірка Android пакує `web/dist` в APK. Результат — `android/app/build/outputs/apk/debug/app-debug.apk`.

## Структура

- `android/` — нативний Kotlin Agent. `AgentService` керує життєвим циклом, `LocalServer` містить HTTP API та WebSocket, `Sessions` відповідає за pairing, `ProjectorControls` виконує Android-команди.
- `web/` — React, TypeScript, Vite, Tailwind CSS і Lucide. `src/agent.ts` містить реальний і демонстраційний клієнти, `src/useAgent.ts` відновлює з’єднання.
- `API.md` — формат запитів, capabilities, стани та коди помилок.
